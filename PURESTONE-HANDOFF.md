# PureStone — Client Handoff

## Linkuri

## Ce este funcțional
- Homepage premium responsive
- Logo PureStone și loading screen cu două forme de piatră
- Catalog materiale cu căutare, filtre, carduri/texturi și detalii
- Simulator vizual
- Configurator cu estimare și WhatsApp
- Portofoliu proiecte
- Secțiune Designeri & Arhitecți cu echipă editabilă
- Admin CMS conectat la Supabase
- Editare texte, contact, echipă și imagini
- Upload imagini în Supabase Storage pentru hero, showroom și echipă
- Conținut public sincronizat din Supabase

## Demo recomandat
1. Deschide homepage-ul pe telefon și arată loading screen-ul + hero-ul.
2. Intră în Colecții și Catalog.
3. Folosește căutarea și schimbă Carduri/Texturi.
4. Arată Simulatorul și Configuratorul.
5. Arată secțiunea Designeri & Arhitecți.
6. Deschide Admin CMS, modifică un text scurt sau o poză și apasă „Publică modificările”.
7. Reîncarcă homepage-ul și arată că modificarea apare public.
