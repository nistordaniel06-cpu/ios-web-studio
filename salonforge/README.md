# SalonForge

SalonForge este un proiect personal derivat din infrastructura și lecțiile PureStone, dar reorientat complet către industria salon/barber.

## V1 — live prototype
- Homepage premium responsive
- Marketplace categories
- Build My Salon calculator
- Configurație recomandată dinamic
- Produse demo salvabile în proiect
- Formular cerere ofertă demo
- Dashboard local pentru proiect, lead-uri și produse
- URL separat: `/salonforge/`

## V2 — product foundation
- Supabase project separat
- Auth proprietar salon / furnizor / admin
- Tabele: salons, projects, suppliers, products, project_items, leads, offers
- Product Admin + Supplier Admin
- CRM pentru lead-uri
- Offer Builder cu PDF
- Upload plan/fotografii
- Favorite + comparații
- Persistență reală cross-device

## V3 — marketplace
- Furnizori verificați
- RFQ: un brief -> mai multe oferte
- Comision / lead fee / subscription furnizor
- Disponibilitate și termene
- Reviews post-purchase
- Catalog multi-furnizor

## V4 — SalonForge AI
- AI brief din text + buget + suprafață
- Recomandare cantități și categorii
- Layout assistant / zoning
- Buget optimizat (smart / premium / luxury)
- Alternative compatibile
- Supplier matching

## Principiu de produs
Nu este doar un magazin de echipamente. SalonForge trebuie să devină sistemul în care un proprietar își construiește proiectul de salon, iar furnizorii concurează pentru acel proiect.
